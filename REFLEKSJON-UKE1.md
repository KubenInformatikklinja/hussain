# Refleksjon - uke 1

## Hva overrasket deg mest med agenten i dag?

Det som overrasket meg mest var at agenten kunne lage filer, installere programmer, teste nettsider og bruke Git uten at jeg måtte gjøre alt selv. Det var også overraskende at den kunne samarbeide med en annen agent om planlegging og implementering.

## Hvilken oppgave gikk dårligst, og hvorfor tror du det gikk slik?

Den dekorerte nettsiden gikk dårligst først, fordi den nye serveren ikke leverte CSS med riktig filtype. Jeg tror dette gikk slik fordi serveren var laget midlertidig og ikke håndterte `.css`-filer riktig.

## Hva er forskjellen på planmodus og vanlig modus – med dine ord?

Planmodus brukes før implementering, når agenten bare skal undersøke og lage en plan. Vanlig modus brukes til å lage, endre og teste selve løsningene. Planmodus gir en sjanse til å gi tilbakemelding før arbeidet starter.

## Hvordan sjekket du at programmene faktisk virket?

Jeg kjørte JavaScript-programmene i terminalen og testet kjente verdier, for eksempel `T = 1`, `T = 10 000` og `T = 1 000 000`. For nettsidene startet jeg lokale servere og brukte nettleseren og `curl` for å kontrollere at HTML, CSS og JavaScript ble levert og at svarene ble riktige.
